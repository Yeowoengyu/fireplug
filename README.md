# FIREPLUG

업로드된 대구광역시 서구 소방시설 엑셀을 기반으로 주변 소화전 3곳과 직선거리를 표시하는 개발용 웹 앱입니다.

## 실행

Node.js 22 이상을 사용합니다.

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

개인 컴퓨터에서는 `npm ci`와 `npm run dev -- --open`으로 실행할 수 있습니다. `npm run build`는 배포용 파일을 만들고, `npm test`는 데이터·거리·추천 로직을 검증합니다.

## 데이터

원본: 소방시설정보_20260917100758862.xlsx, 719개 시설(소화전 718개·소화수조 1개). 원본의 동 이름과 도로명 및 샘플 주소 조회를 바탕으로 대구 서구 주소로 정규화했습니다. Kakao Local 주소 API를 이용해 도로명주소 또는 지번주소에 일치하는 WGS84 좌표를 변환했습니다. 좌표 미확인 시설과 소화수조는 소화전 지도에서 제외합니다. GISID와 원본 행 번호로 각 시설을 구분합니다. `src/dataset-summary.json`에 반영·미확인 수가 기록됩니다.

카카오 REST API 키는 서버 환경변수로만 읽습니다. 키 값은 브라우저 코드와 다운로드 파일에 포함하지 않습니다. 저장된 주소와 지도 표시는 키 없이 실행되며, 새로운 주소의 실시간 검색은 서버 환경변수 `KAKAO_REST_API_KEY`가 필요합니다.

## 기능과 범위

- 엑셀 데이터에서 좌표가 확인된 주소 검색 및 자동완성
- 서버에서 Kakao API로 대구 서구의 새로운 상세 주소 검색
- 빠른 동별 검색, 가까운 소화전 3개, 거리순 목록
- 지도 마커, GISID·주소·시설 종류 상세 정보
- 점검 미확인 필터 및 모바일 화면

등록된 주소는 키 없이 검색할 수 있습니다. 새로운 화재 주소는 서버의 `KAKAO_REST_API_KEY`가 있어야 조회되며, 데이터 범위인 대구 서구만 지원합니다. Vite 개발·미리보기 서버와 `npm start` Node 서버에 주소 API가 연결돼 있습니다. 정적 파일만 배포하면 실시간 주소 검색은 제공되지 않습니다. 주소 좌표는 건물·필지 기준 추정값이며 실제 소화전 설치 지점과 다를 수 있습니다. 여러 소화전이 같은 주소 좌표를 공유할 수 있습니다. 공식 GISID 좌표 또는 현장 확인으로 보완하세요. 거리는 직선거리이며 도로 이동거리가 아닙니다.

원본에는 점검 결과가 없습니다. 마지막 점검일·수압 등 이전 데모 값을 제거했고 모든 점검 상태를 '미확인'으로 표시합니다. 현재는 상태 기반 사용 추천을 하지 않습니다. 실제 출동 판단에는 공식 위치와 점검 정보가 필요합니다.

배경 지도는 OpenStreetMap, 폰트는 Google Fonts를 사용해 외부 네트워크가 필요합니다. 지도 로딩 실패 시 안내 메시지를 표시합니다. 환경 게시와 웹사이트 배포는 별개입니다.

## 서버 실행 및 키 관리

`npm run build` 후 `npm start`로 API와 빌드된 앱을 함께 제공합니다. 기본 포트는 5173이며 `PORT`로 변경할 수 있습니다. 실시간 검색은 서버 프로세스에 `KAKAO_REST_API_KEY`를 안전하게 주입하세요. VITE_ 접두사를 쓰면 안 됩니다. 현재 클라우드에서는 등록된 비밀 변수를 재사용합니다. HTTPS_PROXY/https_proxy가 있는 환경에서는 지원되는 HTTPS 프록시를 사용하며 TLS 인증서 검증을 유지합니다. 서버는 API 인증 오류를 키 값 없이 안내합니다.
